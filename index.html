Установка

Три шага — и готово

Установщик в том же стиле Material You, с анимациями. Права администратора не нужны.

1

Скачайте

Для Windows — установщик NotepadYou-Setup.exe, для Mac — образ NotepadYou.dmg.

2

Установите

Windows: запустите файл и нажмите «Установить». Mac: откройте .dmg и перетащите Notepad You в «Программы».

3

Пишите

Откройте Notepad You — короткое обучение покажет, где что находится.

Вопросы

Частые вопросы

Windows пишет «Система Windows защитила ваш компьютер». Что делать?

Так SmartScreen реагирует на новые программы без платной цифровой подписи. Нажмите Подробнее, затем Выполнить в любом случае.

Скачивайте установщик только с этого сайта.

Mac пишет «Не удаётся проверить разработчика». Как открыть?

У Notepad You нет платной подписи Apple, поэтому при первом запуске macOS предупреждает. Один раз сделайте так:

Откройте Системные настройки → Конфиденциальность и безопасность, пролистайте вниз и нажмите Всё равно открыть рядом с Notepad You. На старых версиях macOS можно просто нажать на приложение правой кнопкой → Открыть.

Это бесплатно?

Да, полностью. Без рекламы, подписок и регистрации.

Где хранятся мои заметки?

Там, куда вы их сохраните: это обычные файлы .md или .txt. Их можно открыть в любом другом редакторе.

Как удалить Notepad You?

Через ярлык «Удалить Notepad You» в меню «Пуск», через «Параметры → Приложения» или отдельным удалятором. Ваши заметки при этом не удаляются.

Нужен ли интернет?

Нет. Интернет нужен только чтобы скачать установщик.
